1.1 — Faceless AI Page

Archetype: @ai.mindshift (Faceless AI Education Page)

Pages like this publish 2–4 AI-generated short videos per day in the "AI facts / future of work / mindset" niche. No face, no voice talent, no studio. Completely machine-operated at the content layer.

End-to-End Workflow Reconstruction

1

Research & Trend Detection

An automated agent scrapes Reddit (r/artificial, r/technology), Twitter/X trending, Google Trends, and competing page comment sections daily. Keywords with velocity spikes ("OpenAI", "job replacement", "AI tools") trigger content slots.

ApifyPerplexity APIn8n schedulerGoogle Trends API
2

Script Generation

A GPT-4o / Claude prompt chain converts the trend topic into a 150–200 word hook-driven script. System prompt is tuned for the page's specific tone (alarming, curiosity-driven, fast-paced). Scripts follow a rigid 3-part structure: Hook → Body Facts → CTA.

Claude / GPT-4oCustom system promptStructured output (JSON)
3

Voiceover Generation

Script is passed to a TTS API. Preferred voices are ElevenLabs "Adam" or "Rachel" clones — trained on the creator's fictional persona voice. Speed: 1.1–1.2x for retention.

ElevenLabs APIPlay.ht (fallback)
4

Visual Generation & Editing

Stock B-roll sourced from Pexels API (free) or licensed Storyblocks. Text overlays generated via Remotion or CapCut API. Subtitles auto-burned with Whisper transcription. Hook frame uses a bold AI-generated thumbnail image (Midjourney/Flux).

Remotion / CreatomatePexels APIWhisper (captions)Flux / Midjourney (thumbs)
5

Quality Gate

Output video passed to a lightweight Claude vision check: "Does this video have subtitles? Is the hook text visible in frame 1? Is there a black bar at bottom?" Simple pass/fail before scheduling. Human review is triggered only on FAIL.

Claude Vision APIFFprobe (video meta check)
6

Scheduling & Posting

Videos queued to Instagram via Meta Graph API (or Buffer/Later as middleware). Optimal times: 7am, 12pm, 7pm local to audience timezone. Caption + hashtags auto-generated by same script model.

Meta Graph APILater / BufferAirtable (content calendar)
7

Analytics & Feedback Loop

Meta Insights API pulls views, watch-time %, shares, and saves every 24 hours. An automated report flags which hooks performed in the top 20% and which flopped. Top-performing scripts are fed back as few-shot examples into the next generation prompt.

Meta Insights APIGoogle Sheets / Notionn8n analytics loop
KEY INSIGHT — FACELESS PAGE

The only human touchpoints are: (1) weekly prompt tuning based on analytics, and (2) occasional quality-gate failures. The entire research-to-post pipeline runs in ~18 minutes per video, fully automated. Estimated cost: $0.40–$0.80 per video at scale.

2.2 — Working Prototype

Automated Script Generation Engine

The prototype I've built solves the single biggest operational bottleneck: producing high-quality, hook-scored, niche-specific scripts at volume without any manual writing. Below is the complete system — a Python-based pipeline that goes from a topic keyword to a production-ready script JSON, with hook quality scoring baked in.

What This Prototype Does

INPUT: A niche keyword + channel config → OUTPUT: 3 script variants with hook scores, estimated watch-time, and TTS-ready text — all in JSON.

Core Script: script_engine.py

# script_engine.py — Matiks AI Content System # Takes a channel config + trend topic → returns scored script variants import anthropic, json client = anthropic.Anthropic() def generate_scripts(channel_config: dict, topic: str) -> dict: """ Generates 3 script variants for a topic, auto-scores hook quality. channel_config = { niche, tone, audience, hook_examples, avg_watch_time } """ SYSTEM_PROMPT = """You are a viral short-form content strategist for Instagram Reels. You write scripts that achieve 60%+ average watch time. Rules: - Hook: first 3 seconds MUST create pattern interrupt. No "hey guys". Start with a number, a controversial claim, or a direct challenge. - Body: 3-5 punchy facts or steps. Max 15 words per sentence. - CTA: specific action (save, share, comment one word). - Total script: 150-180 words. Spoken in 45-55 seconds. Output ONLY valid JSON. No markdown, no preamble.""" USER_PROMPT = f""" Channel niche: {channel_config['niche']} Target tone: {channel_config['tone']} Audience: {channel_config['audience']} Topic: {topic} Proven hooks from this channel: {json.dumps(channel_config['hook_examples'], indent=2)} Generate 3 script variants with DIFFERENT hook styles (stat-based, challenge-based, controversial). For each, include: - hook_text (first line only) - hook_score (1-10, based on pattern interrupt strength) - full_script (complete TTS-ready text) - estimated_watch_pct (your prediction: 0-100) - caption (Instagram caption, 150 chars max) - hashtags (array of 15 relevant tags) Return as JSON array of 3 objects. """ response = client.messages.create( model="claude-opus-4-5", max_tokens=2000, messages=[{"role": "user", "content": USER_PROMPT}], system=SYSTEM_PROMPT ) scripts = json.loads(response.content[0].text) # Auto-select best script (highest hook_score × estimated_watch_pct) best = max(scripts, key=lambda s: s['hook_score'] * s['estimated_watch_pct']) best['selected'] = True return { "topic": topic, "channel": channel_config['niche'], "scripts": scripts, "selected_script": best, "production_ready": best['hook_score'] >= 7 } # --- Hook Quality Evaluator (second AI pass) --- def evaluate_hook(hook_text: str, niche: str) -> dict: """Strict hook evaluation — rejects weak hooks before TTS.""" eval_response = client.messages.create( model="claude-haiku-4-5", # Haiku for speed + cost on eval tasks max_tokens=200, messages=[{ "role": "user", "content": f"""Rate this Instagram Reel hook for the {niche} niche. Hook: "{hook_text}" Score 1-10. Penalize: generic openings, "hey guys", questions without stakes. Reward: numbers, controversy, direct challenge, unexpected claim. Return JSON: {{"score": N, "reason": "one sentence", "approved": true/false}}""" }] ) return json.loads(eval_response.content[0].text) # --- Example Run --- if __name__ == "__main__": channel = { "niche": "AI tools for productivity", "tone": "authoritative but accessible", "audience": "25-40yo professionals wanting to work smarter", "hook_examples": [ "ChatGPT does this in 4 seconds. Most people take 3 hours.", "I replaced my entire research team with one AI prompt.", "5 AI tools that feel illegal to know about." ] } result = generate_scripts(channel, topic="Claude Artifacts for automating reports") print(json.dumps(result, indent=2))

Airtable Automation: Script → Production Queue

A

Airtable Base Structure

Three linked tables: Channels → Content Queue → Analytics. Scripts land in Content Queue with status "pending_review". Hook score ≥ 7 auto-advances to "approved".

B

n8n Trigger on New "Approved" Row

When a script hits "approved" status in Airtable, n8n automatically fires the ElevenLabs TTS node, then passes the audio + script to Creatomate for rendering. No human needed.

C

Render Webhook → Schedule

Creatomate sends a webhook on render completion. n8n receives it, runs the Claude vision QA check, then pushes to Meta Graph API at the scheduled time. Airtable status updated to "posted".

2.3 — Scale

One Operator, 10 Channels, 20+ Reels/Day

Scaling is achieved through configuration, not replication. The pipeline is identical for every channel. Niche, tone, voice, and schedule are variables — not separate workflows.

⚙️

Channel Config as Code

Each channel is a JSON config in Airtable. Adding a new channel = adding one row. The operator fills in niche, tone, 5 example hooks, and posting times. Everything else inherits from the master workflow. Time to spin up a new channel: ~15 minutes.

🔄

Parallel Execution via n8n

n8n runs one workflow instance per channel simultaneously. 10 channels fire at 6am → 10 parallel trend research jobs → 10 script batches → 20 renders queued. No sequential bottleneck.

📅

48-Hour Content Buffer

The system always maintains a 48-hour buffer of approved scripts. If trend research fails on a given day (API rate limit, no strong topics), the evergreen pool fills the slot automatically. No missed posting days.

📈

Compounding Analytics

The feedback loop runs per-channel. Channel A's top hooks don't pollute Channel B's prompt. Each channel independently discovers what resonates with its audience. Over 3–6 months, each channel's content quality compounds as its winning hook library grows.

🧑‍💻

Operator's Actual Weekly Tasks

Review the weekly analytics digest (30 min). Update 2–3 prompt examples if a new format is working. Handle any QA failures flagged by the system (rare). Review the content buffer for quality issues. That's it. No scripting, no editing, no scheduling.

CLOSING THESIS

The operator's job is not to create content. It is to own the intelligence layer — the prompts, the quality standards, the feedback loops — that makes the machine produce better content over time. Scale is not adding more people. It is making the feedback loop tighter and the prompts sharper. Every week the system runs, it gets better. That is the compound interest of AI-first content operations.
